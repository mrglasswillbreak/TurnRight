# Support

## Where to ask for help

- Usage and workflow questions: open a **Discussion** or issue with the "support" label.
- Bugs: use the bug report issue template.
- Feature requests: use the feature request issue template.

## Before opening support requests

- Check `/README.md` and `/docs/README.md`.
- Check `/docs/DEPLOYMENT.md` and `/docs/CONFIGURATION.md` for setup and environment details.
- Check `/docs/OPERATIONS-CHECKLIST.md` for release/import/source workflow troubleshooting.

## Security disclosures

For potential vulnerabilities, follow `/SECURITY.md` and avoid public disclosure before triage.
