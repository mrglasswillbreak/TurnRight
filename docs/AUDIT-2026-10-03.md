# Application performance and quality audit — 3 October 2026

This audit starts at `14aed84`, after the campus-silhouette release. It covers public navigation and discovery, campus-scoped state, editor/layer workflows, photos and model authoring, imports, revision conflicts, recovery, offline packages and deployment budgets. It uses isolated owner/API fixtures and the exact published LASU and UNILAG packages. No campus content or routing permissions are changed.

## Reproduced defects and fixes

| Finding | Repair and verification |
| --- | --- |
| Expanded attribution text sat behind the mobile panel and retained small, low-contrast default styling. | Credits start compact, open in a bounded scrollable top-corner panel and use theme colours and a 44 px keyboard/touch toggle. Chromium/WebKit regressions cover desktop/mobile, both themes and the expanded main panel. All source credits remain available. |
| The browser title, search description and installable-app name still identified every campus as LASU. | Use campus-neutral application metadata and verify the generated HTML and PWA manifest. Existing installed-app names can take a browser refresh to update. |
| Initial road display submitted every campus feature to a second GeoJSON source. | Supply paths only until clipping completes; retain full original paths in the campus source for editing. Tag asynchronous results with their input snapshot so the previous campus cannot briefly supply the new campus's roads. The browser checks the actual source contents. |
| Building selection repeatedly scanned all destinations and resolved the same associations. An empty selection performed the same work. | Index associations per immutable campus snapshot, preserving explicit links, aliases and first-match precedence. Skip the empty-selection scan. Unit tests cover precedence and separation between snapshots. |
| Searching after scrolling the virtualized layer table left matching results above the viewport. | Reset both the DOM scroll position and virtual window when changing search, layer or explorer tab; clamp the window after removal. The regression reproduces the old 4,657 px residual scroll and checks reachable search results. |
| Layer scrolling recalculated classifications, source searches, feature counts and stale-surface checks. | Cache feature identities, search strings, layer statistics, filtered rows and regeneration counts until their inputs change. Selection membership uses a set; bulk lookups use an index. |
| Layer tabs omitted arrow-key navigation; virtual table row numbering excluded its header. | Add Left/Right/Home/End navigation and correct row metadata. Browser tests activate Features with the keyboard before searching. |
| Changing building opacity, model coverage or selection replaced filters and lost configured layer zoom ranges. | Restore limits only for changed filters. Optional GIS paint installation no longer runs for every model response or place selection. A real MapLibre regression reproduces and verifies the opacity case. |
| Two rapid draft saves could reuse a timestamp, accepting a stale revision. | Migration 022 makes each updated record's revision strictly greater than its predecessor, even if the clock repeats or moves backwards. PostgreSQL tests check immediate writes, an intentionally future timestamp, stale rejection, rollback and idempotent retries. |
| An unused scaffolding CLI brought 220 unnecessary installed packages and advisory-affected transitive dependencies. | Remove the unused CLI; update the remaining build-only `fast-uri`, `brace-expansion` and `serialize-javascript` packages within compatible ranges. No application API changes. The dated dependency receipt distinguishes the original production-only scan from the final full scan. |
| Worker module failures could escape the road worker or leave a fallback worker alive. | Return a failure message to the existing fallback and terminate failed work. Lifecycle tests cover worker failure, page exit and cached-page restoration. |

[Dependency scan receipt](assets/app-audit-dependencies-2026-10-03.json): the initial production dependency tree had nine advisory entries (seven high, two moderate), all through unused CLI/build tooling; the final full-tree scan reports zero known advisories. This registry snapshot is not a guarantee of security or evidence of an exploitable public endpoint.

The audit also found two stale campus-chooser assertions: the non-modal dialog leaves the campus location button accessible behind it. Assertions and clicks now target the chooser itself. Polygon 96's persistence test now waits for save acknowledgement and map processing before reload; its earlier failure came from WebKit cancelling Vite's injected worker environment module during navigation. It still verifies all 6,094 vertices, 56 holes, saved width and reload, with no browser errors.

## Measurements and interpretation

The fixtures are **LASU `lasu-4895a363b403`** (609 features, 393 buildings, 220 places) and **UNILAG `unilag-faa044ebdd24`** (3,928 features, 723 buildings, 116 places). They are the current published packages, not the older 420-building benchmark fixture.

| Controlled processing measurement | LASU before → after | UNILAG before → after |
| --- | ---: | ---: |
| Initial road-source JSON payload | 1,009,110 → 102,856 bytes | 6,348,227 → 184,873 bytes |
| Resolve buildings for every destination, median of seven Node runs | 723.6 → 16.6 ms | 993.6 → 16.3 ms |

The payload reductions are 89.8% and 97.1%. These are renderer input bytes, not network download savings. The lookup measurement is a batch traversal, not a single click or field INP. Clipping remains in a worker; the audit does not claim to have accelerated the geometry algorithm.

The public-map harness measures navigation to the first loaded map with rendered features and campus discovery installed, using a production build, fresh browser contexts, software WebGL, desktop/phone viewports and 1×/4× CPU. It records long tasks, transfer bytes and heap use. It does not wait for every optional model and is not a network, battery or physical-device benchmark. Three samples per campus/profile are too few to claim a field percentile. Whole-map startup remains a separate target; lookup improvements alone do not establish a faster overall page load.

The [raw processing comparison](assets/app-audit-processing-2026-10-03.json), [public startup samples](assets/app-audit-public-startup-2026-10-03.json) and [twenty model-workspace trials](model-editor-audit-2026-10-03.json) retain provenance. The local host is an Intel i5-1155G7 with 8 GiB RAM, Node 22.23.3 and software WebGL. Startup measurements show no consistent end-to-end improvement; every trial reports zero application errors. Full-campus startup and dense throttled model interaction remain open targets.

The model harness measures published input/click p95 at 22.7/93.3 ms (1× CPU) and 84.4/199.9 ms (4×). Its synthetic 100-detail wall records 32.5/130.2 ms and 244.7/228.2 ms. No model generation occurs while typing, and closing the workspace leaves consistent worker/GPU counts across independent trials. These measurements exclude network and have no newly rerun historical model baseline.

## Verification and release record

The unmodified baseline audit exposed the revision collision, outdated chooser assertions and the development-worker reload race. The [final application run](https://github.com/mrglasswillbreak/TurnRight/actions/runs/37125078717) passes all eight jobs: 699 unit tests across 97 files, four Chromium shards, both WebKit shards, photo workflows and offline suites, lint/typechecks and configured budgets. Host Python runs 60 tests with four driver skips; the separate [pinned GIS run](https://github.com/mrglasswillbreak/TurnRight/actions/runs/37101541059) passes 30 integration tests and the actual private-workspace mount. Local unit/lint/build checks were rerun after the dependency cleanup, with unchanged bundle sizes. Exact browser totals and deployed acceptance are recorded in [Production](PRODUCTION.md).

Migration `022_monotonic_editor_revisions.sql` is additive and compatible with existing clients. It updates no existing draft rows and requires no public package rebuild. Keep it when rolling back application code. The production trigger was verified after application; draft counts remained LASU 147 and UNILAG 201.

## Remaining limits

- Windows Playwright WebKit can render a blank map after resizing an already-open page from desktop back to phone width. The Linux production capture matrix must verify pixels as well as camera/data state; this has not been established as a Safari device defect.
- Full-campus startup, dense model interaction under 4× CPU (over 200 ms) and retained-original image memory remain profiling targets. The new model study above has its own fixture and date; photo interaction timings remain the earlier dated study.
- Public and owner startup bundles have only 711 and 827 gzip bytes of remaining budget. New optional interfaces must stay lazy-loaded; passing today’s limit does not provide substantial room for future shared imports.
- Existing eight explicit-`any` lint warnings remain. Driver-dependent Python checks require the pinned GIS container; host skips are not full driver verification.
- Phone layouts and simulated GPS do not establish physical-device reliability, background guidance, route safety or accessible entrances. Field verification remains open.
- Cross-campus routes, interior-room navigation, raster/scanned-map alignment and proprietary DWG conversion remain outside the implemented product scope.

README and current operating guides describe supported behavior. Older dated audits and source research retain their original evidence and are labelled historical rather than rewritten as current results.
